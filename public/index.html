Stripe Connect — Express accounts, destination charges, application fees

A reference integration in test mode. Sellers onboard as Express connected accounts; buyers pay on the platform; funds land on the seller and the platform keeps an application fee.

The point of this demo: there is no single Stripe field meaning “onboarding is done.” The return_url redirect only means the flow was entered and exited. A seller is ready only when charges_enabled and details_submitted are true and requirements.currently_due is empty. This UI shows all three separately, on purpose.
